# HP 算法（Oura → PUT /v1/energy）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一个常驻进程每 10 分钟从 Oura API v2 取数，从头重放算出 HP，然后写入 `PUT /v1/energy`。显示服务和三端客户端不做任何改动。

**Architecture:**
- 纯函数模型 `hp_model.py` 不做任何 IO。输入是 Oura 原始 JSON 和 `now`，输出是 `Result`。
- `oura_auth.py` 负责 OAuth 和令牌，`oura_client.py` 负责取数。
- `hp_usage.py` 是 CLI 和常驻循环：取数 → `compute` → `energy_usage.build_payload` → `display_push.push`。

**Tech Stack:** Python 3 标准库（`urllib`、`http.server`、`fcntl`、`dataclasses`、`statistics`、`unittest`），不引入第三方依赖。

**Spec:** `docs/superpowers/specs/2026-11-25-hp-oura-spec.md`。所有公式和阈值以 spec 为准，设计来源见 `docs/hp-algorithm-design.md`。

## Global Constraints

- 只用标准库。所有新文件放在 `server/`。测试命名为 `server/test_*.py`，在 `server/` 目录下用 `python3 -m unittest <module> -v` 运行。
- `hp_model.py` 不得 import 网络、文件或 `display_push` 相关模块。
- 不修改 `display_server.py`、`display_push.py`、`energy_usage.py` 和任何客户端代码。
- 时区：函数一律接收 `tz` 参数。生产环境取 `datetime.now().astimezone().tzinfo`，测试用 `timezone(timedelta(hours=8))`。
- 输出固定为 `source="estimated"`、`stale_after_seconds=1800`、`name="HP"`。
- 所有请求的 User-Agent 为 `xiaobucubic-hp/1`。OAuth scope 为 `personal daily heartrate workout`。回调地址默认 `http://127.0.0.1:8765/callback`。
- **status 文案**（必须一字不差）：
  - 分数段：`充沛`（≥85）、`良好`（≥65）、`尚可`（≥45）、`偏低`（≥20）、`告急`（≥5）、`见底`。
  - 特殊情形：`待同步`（null）、`待授权`（未授权）。
- **note 文案**（必须一字不差）：`睡眠预估`、`{h}h未同步`、`准备度{R}`、`运动中`、`生理压力高`、`小憩回血`、`静息恢复`、`建议休息`、`校准中`。
- **level 取整**：采用四舍五入（`math.floor(x + 0.5)`），不用 Python 的 `round()`，因为后者会把 84.5 舍成 84。这是对 spec「round()」的明确解释。
- **提交范围**：
  - `server/energy_usage.py` 和 `display_server.py` 中的 energy 代码，是用户**尚未提交**的工作。`.gitignore` 和 `server/README.md` 里也有用户未提交的改动。
  - 每个任务只 `git add` 本任务新建的文件，**不得**暂存上述文件。
  - 对 `.gitignore` 和 `server/README.md` 的修改保留在工作区，最后交给用户一起提交。
- 在主工作区直接实现，不建 worktree，因为 HP 依赖上面那些未提交的 energy 代码。

## Review Focus

1. **戒指时区与系统时区不同**（出差，时间带 `+09:00`）：一律换算成 Unix 秒，「本地日」按 `tz` 计算，不能崩溃。测试在 Task 1。
2. **Oura 字段为 null**（`average_hrv`、`lowest_heart_rate`、`score`、`met.items` 中的元素、`class_5_min`）：跳过这些值，不能抛 `TypeError`。测试在 Task 1 和 Task 2。
3. **令牌文件缺失或损坏**：抛 `AuthRequired`，最终推送「待授权」，不能抛 `JSONDecodeError`。测试在 Task 5。
4. **授权缺少某个 scope，Oura 对该集合返回 403**：报出集合名并放弃本轮，不推送错误数据。测试在 Task 6。
5. **`--follow` 运行中显示服务暂时不可达**：记日志后继续下一轮，进程不退出。测试在 Task 7。
