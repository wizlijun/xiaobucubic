# StandIt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 原生 iOS App「StandIt」：打开即全屏轮播 `/v1/display` 的额度、天气、便签；附带一个只占 StandBy 一半的 `systemSmall` 小组件。

**Architecture:** XcodeGen 生成工程；`Shared/` 为 App 与 Widget 共用的纯 Swift 模型（移植 `apps/xiaobucubic/package/display_model.lua`）、网络、Keychain 配置与 App Group 缓存；App 与 Widget 各自拉取接口。

**Tech Stack:** Swift 6、SwiftUI、WidgetKit、Security（Keychain）、XCTest；XcodeGen（`/opt/homebrew/bin/xcodegen`）；Xcode 27.2；部署目标 iOS 27.0。

**Spec:** `docs/superpowers/specs/2026-11-18-standit-design.md`

## Global Constraints

- 显示名 `StandIt`；工程 / target：`StandIt`、`StandItWidget`、`StandItTests`；Bundle ID `$(STANDIT_BUNDLE_PREFIX).standit`、`.standit.widget`。
- 签名团队与 Bundle 前缀只写在 `apps/standit/Local.xcconfig`（Git 忽略）；仓库提交 `Local.xcconfig.example`。
- App Group `group.$(STANDIT_BUNDLE_PREFIX).standit`；Keychain Access Group `$(AppIdentifierPrefix)$(STANDIT_BUNDLE_PREFIX).standit.shared`。
- 只用系统框架，无第三方依赖。
- 数据规则以 `apps/xiaobucubic/API.md` 为准；时区固定 UTC+8（480 分钟）。
- ATS：两个 target 的 Info.plist 设 `NSAllowsArbitraryLoads = YES`（README 注明改 HTTPS 后移除）。
- token、接入点只存 Keychain，不进 UserDefaults、不打印。
- 不使用 `UIScreen.main`；尺寸全部来自 `GeometryReader`。
- 配色：底 `#070C12`、面板 `#111C28`、文字 `#F0F5FC`、次要 `#8497AC`、卡片循环 `#6DE1C2` / `#83B6FF` / `#FFC078`、警告 `#FFD166`、警戒 `#FF5F6D`；便签纸 `#FFF2A6` / `#DDEEB4` / `#F7B6B2` / `#B9DFF2`，便签文字 `#30382D`。

## Review Focus

1. 接口返回 401/403 或坏 JSON 时缓存不能被覆盖，界面仍显示旧数据并标出错误 → Task 3 `testFailureKeepsCache`。
2. 订阅有两个窗口且次窗口更低时，小组件排序按最低窗口 → Task 5 `testLowestThreeQuotas`。
3. 便签全部过期后小组件时间线只剩额度卡，不出现空白卡 → Task 5 `testExpiredNotesSkipped`。
4. 0 个订阅、`weather: null` 时页面不崩溃、显示空状态 → Task 4 预览 `empty` + Task 2 `testMinimalDocument`。
5. 接入点粘贴时带首尾空白 / 末尾斜杠 / 已含 `/v1/display` → Task 3 `testEndpointNormalization`。
